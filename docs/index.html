Chrome DevTools Extension

API Cartographer

Use an app while DevTools is open, and API Cartographer maps the traffic behind it: endpoints grouped by normalized path, inferred request and response schemas, status patterns, and an OpenAPI 3.1 draft you can export. Everything runs locally — the extension makes no network requests of its own.

What it does

Groups traffic into endpoints

Numeric ids, UUIDs, and hashes in paths collapse into templates like /users/{id}, so a hundred requests read as a handful of endpoints.

Infers schemas across samples

Request and response bodies are merged across multiple samples, handling nested arrays, nullable fields, and mixed types.

Exports OpenAPI, Markdown, and Postman

Copy or download an OpenAPI 3.1 document, a Markdown API report with an endpoint table and per-endpoint details, or a Postman Collection v2.1 file with base URL variables and saved response examples.

Redacts before sharing

A standard profile masks auth headers and token-like values; a strict profile allowlists headers, masks every query value, and scrubs emails and IPs from bodies.

Sessions and diffs

Save named captures, restore them later, and compare the current capture against one to see which endpoints are new, gone, or returning different statuses.

SDK hints and notes

Generate ready-to-paste cURL, JavaScript fetch, and Python requests snippets, and keep your own notes per endpoint.

Install from source

There is no Chrome Web Store listing yet. Build it locally and load the unpacked extension:

git clone https://github.com/Pranai820/api-cartographer.git
cd api-cartographer
npm install
npm run build
  1. Open chrome://extensions.
  2. Enable Developer mode.
  3. Choose Load unpacked.
  4. Select the repo's dist folder.
  5. Open DevTools on any page and pick the API Cartographer panel.

Capture only runs while that DevTools panel is open. Use the app you want to map, then filter, inspect, and export.

Privacy

Captured traffic stays in chrome.storage.local on your machine, capped at the most recent 500 requests. The extension has no analytics and no remote endpoints. Redaction runs before anything is rendered or exported; project-data backups intentionally keep unredacted data for local restore. See PRIVACY.md for specifics.
